# Código de conducta

Este proyecto adopta el espíritu del [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Nuestro compromiso

Queremos una comunidad abierta y respetuosa, libre de acoso, sin importar edad, discapacidad, etnia, identidad o expresión de género, nivel de experiencia, nacionalidad, apariencia, religión u orientación.

## Comportamiento esperado

- Ser respetuoso y constructivo; aceptar críticas técnicas con buena fe.
- Centrarse en lo que es mejor para el proyecto y las personas usuarias.
- Dar y recibir feedback con empatía.

## Comportamiento inaceptable

- Acoso, insultos, ataques personales o discriminación.
- Publicar datos privados de otras personas sin permiso.
- Usar el proyecto para fines abusivos (spam masivo de postulaciones, suplantación, engaño a empleadores).

## Aplicación

Los mantenedores pueden editar o eliminar contribuciones y vetar a quien incumpla estas normas. Reporta incidentes abriendo un aviso privado de seguridad en GitHub (Security > Report a vulnerability) o contactando a los mantenedores por su perfil de GitHub.
